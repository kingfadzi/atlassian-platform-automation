# Execution boundary

**No live adapters, diff engine, state manager or controller are implemented.** The blocked commands are not dry-run adapters.

Reuse supported tools/APIs after capability proof. Define read, plan, apply and behavioural verification per managed property, with identity scope, concurrency, retry, stop and recovery rules.

Use protected runtime stores for generated mappings, checkpoints, plans and evidence. Never infer deletion authority from omitted declarations; re-read uncertain results before retrying.
