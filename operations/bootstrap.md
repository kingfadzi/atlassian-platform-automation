# Bootstrap

**Local setup does not configure Atlassian.** Install development dependencies, run `make check`, then verify pinned sources with `make check-sources`.

Before a future lab binding:

- Confirm tenant ownership, scope, plans and feature rollout without claiming enterprise equivalence.
- Establish isolated lab identities/credentials, protected runtime stores and independent failure routing.
- Verify identity, sharing, execution and audit prerequisites; record manual/unsupported steps explicitly.
- Authorise the exact live actions separately. Adding credentials or changing a flag cannot enable this scaffold.
- Choose policy/execution tools and implement one bounded path with reviewed tests.
